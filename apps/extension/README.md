# PlateGo Chrome MV3 插件

插件工作台可在没有网页和后端时独立打开；全国 31 个地区的固定模拟号池随构建产物打包。上海 `official-mock` 仍是本地样机验收入口。官方模拟（`/veh1/netxh/main?gnid=1001`）和正式选号（`/veh1/netxh?gnid=1001`，且精确命中 `zbxh/sjxh` 内嵌页面）均允许本机只读号码、规则高亮、候选筛选和当前意向填入；未知官方路由始终保持安全关闭。

## 构建与加载

在项目根目录执行：

```sh
npm run check -w @platego/extension
```

然后打开 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”，目录为：

```text
apps/extension/dist
```

Chrome 151 正式版会忽略命令行 `--load-extension`；验收时应使用上述界面加载方式。工作台无需后端即可使用固定模拟数据。可选本地后端默认地址为 `http://127.0.0.1:8789`。

## 页面安全边界

- 本地样机：仅 `http://127.0.0.1:4173/official-mock` 或同端口 `localhost`，且必须满足 `shanghai-v1` 脱敏页面结构契约。
- 官方模拟选号：仅当顶层路径为 `/veh1/netxh/main` 且查询参数 `gnid=1001` 时，允许读取随机号码；助手保持用户选择的随机或自编标签，不主动切换。用户亲自进入自编后，助手可按 `LI.active` 白键遍历可用号池并填入当前意向、把当前批次加入本机候选。确认信息页才出现合格证识别与一键填入。选号 iframe 不可读时不填入选号。
- 车辆档案只存在 Chrome 本地存储（`chrome.storage.local`）。可选手填或把合格证照片拖入识别；识别与编辑都会自动保存。OCR.space 密钥和语言在插件弹窗或完整工作台的「时限密钥」页配置。图片不经过 PlateGo 服务器。确认页可一键填入合格证编号、识别代号和号牌种类。品牌型号查询窗口由你亲自打开和关闭；窗口打开后助手分两栏显示品牌和型号，一点即可填入并点查询。选择、确定、关闭仍由你点击。你点确定后，选中结果写回本机记录。核对在确认页放大合格证对应位置。请先开查询窗再填确认页。下一步要点的页面栏位会用绿色描边标出。填写后可将鼠标移到「核对」上放大查看合格证对应区域。编号、型号里若出现 OO/00、I/1 等常见 OCR 易混字，栏位会标红提醒核对。插件不会点击选择、确定、提交或继续。
- 正式上海选号：只在顶层 `/veh1/netxh?gnid=1001` 且可见内嵌页面精确为 `/veh1/netxh/zbxh` 或 `/veh1/netxh/sjxh` 时开放。随机页只读并高亮；自编页只读取已加载的运行时规则快照，数据以 `live-local` 仅存本机。如果快照不可用，正式页不会退回耗时逐键遍历。其他官方页继续保持安全关闭。
- 随机选号：页面初始为空；只有用户亲自点击“随机一次”或官方换批后，插件才只读当前号码。相同数字出现 2 次、三位顺序号、好多数出现 3 次时描边；三连或 AABB、四位顺序或数字回环、同一数字 4 次或多个数字同时命中，以及位置/顺序规则命中时增加同色静态泛光。相同数字与好多数都可指定目标数字，留空即匹配全部。插件不点击号码、“随机一次”或“换一批”。
- 自编选号：本地样机在用户点击一次启动后，只向样机输入框写入前缀并退格遍历，结束时恢复探针输入框原值。官方页只有在你亲自进入自编并点击开始、白键可见后才读取。主路径从内嵌页面已加载的运行时缓存只读取得完整 `hdArr`、`hphmRegex[]` 和长度；每扩展一个前缀都按官方排除规则移除灰键，再用当前 `LI.active` 白键做一致性核验。模拟页在快照不完整时可受控退回逐键遍历；正式页为节省选号时间直接停止并使用已保存号池或手动号码。固定前缀只有「沪」。用户亲自提交一组后，插件通过“剩余自编次数下降”回执自动推进到下一组；上一轮未选中的号码会灰色排除并禁止再次加入，只有用户明确点击“恢复上一轮备用”才会撤销；结果标成「可编号段快照/候选组合」，不是已确认实时可用。确认选号仍由你点击。规则快照写入 Chrome 本地存储。不得请求 `/getHdList` 或 `/validConfirmHphm`，也不得读取车辆识别代号、浏览器会话凭据、验证码或 `validToken`。
- 候选更新、公共模拟观察上传、分组填入都是互相独立的用户点击动作。官方主机上的上传按钮不会出现。
- 内容脚本没有针对验证、换批、确认选号或提交的页面 `.click()`、表单 `submit()`、`requestSubmit()`、鼠标事件或键盘事件合成路径。官方模拟键盘仅通过 `HTMLElement.prototype.click.call` 激活已开放的 `LI.active` 键，并排除 `#submit`、`.btns` 与含确认/提交文案的键。
- 公共观察后台仅接受 `simulation + official-mock + 310000`，并拒绝真实域名发送者、`live`、私有字段和旧端口 `8787`。

公共覆盖度契约保留 `complete | partial | position-only | unknown` 四种代码值。本地上海 v1 完整遍历当前只产生 `complete | partial | unknown`；`position-only` 为未来只能安全观察位置可用性的适配器保留。

## 手动验收

1. 启动网页样机并进入 `/official-mock`，由用户逐步完成 LOGIN、基本信息、确认、服务说明和手机验证等当前可见入口；确认信息页必须由用户先勾选确认框，再点击继续。插件在 `SELECTION_READY` 前不得推进页面。
2. 确认随机选号页初始没有号码；由用户亲自点击“随机一次”后，确认助手只出现推荐类型勾选，命中的号码外框被描边，样机号码按钮选中态没有被插件改写。
3. 由用户进入自编选号并点击“开始完整采集”；确认覆盖度为 `complete`、完整组合为 240，且首个输入框的原值（包括非空值）已恢复。
4. 检查保留、移除、未知、新增四类差异；分别点击本机更新与公共模拟观察上传。
5. 按组填入候选；确认样机的验证结果仍为空，并由用户自行决定是否点击“验证本组”。插件不得点击验证、随机号码、换批或“确认选号”。
6. 打开插件工作台，确认 Chrome 本地存储中的候选更新已同步显示。
7. 在已登录的官方模拟或正式选号页，由你完成入口与验证码并亲自选择随机/自编。随机页只读当前批次并在号码外框高亮；自编页由你点击开始后，助手读取白键规则、筛选本机号池并可按组填入。助手不会主动切换标签，也不得替你点击开始、换批、验证或确认选号。

`npm run smoke:fixture -w @platego/extension -- http://127.0.0.1:9229` 可在已手动加载插件且开启远程调试的临时 Chrome 配置中复跑上述闭环。配套内存验收后端为 `npm run fixture:api -w @platego/extension`，默认只监听 IPv6 本机回环地址的 `8789` 端口。
