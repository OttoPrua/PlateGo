三步完成首次安装

  1. 下载并完整解压 ZIP，打开 PlateGo-Chrome-v{{VERSION}} 文件夹。
  2. macOS 双击 Install.command；Windows 双击 Install-Windows.cmd。引导会把扩展复制到固定的个人目录，并打开安装说明。若系统阻止运行，请按包内说明手动安装，无需关闭系统安全防护。
  3. 在地址栏输入 chrome://extensions，开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择引导打开的 extension 文件夹。浏览器安装确认由你完成。

macOS 固定目录：~/Library/Application Support/PlateGo/extension
Windows 固定目录：%LOCALAPPDATA%\PlateGo\extension

更新时退出正在进行的选号流程，运行新版安装引导，再到扩展管理页点击 PlateGo 的“重新加载”。也可把解压后的 extension 留在固定位置手动加载；加载后不要移动或删除该目录。更换加载路径可能改变扩展标识并影响原有本机数据。
