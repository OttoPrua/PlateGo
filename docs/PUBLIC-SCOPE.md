# PlateGo 公开边界

本工作区同时可能包含公开源码和仅存在于本机的私有目录。公开 Git 基线只索引插件、网页、公共契约和固定模拟数据；私有目录通过 `.gitignore` 排除，不被删除。

## 公开部分

- Chrome MV3 插件工作台、页面助手、后台脚本和插件构建/契约测试；
- 网页模拟器与上海流程样机（作为开发/历史内容保留）；
- `packages/core` 公共契约：配置编码、筛选评分、选号状态机、观察命名空间规则；
- `packages/sim-data` 固定、可复现的模拟号池；
- `packages/client-app` 共享界面，包括在缺少本地私有后端时安全降级的可选连接入口。

网页和插件都可以只靠固定模拟数据独立运行。可选的本机回环地址出现在插件与界面中，用于连接本机私有伴生服务；该服务的实现不在公开索引中。

## 必须保持私有的部分

- `services/pool-api/**`：现有后端共享实现；
- 购买、支付、激活、时限密钥校验的服务端实现与任何密钥材料；
- `private/**`：官方网页私有采集、用户车辆资料和合格证等；
- `**/node_modules/**`、`**/dist/**`、`**/var/**`；
- 环境变量、凭据、令牌、浏览器会话。

本机检出里上述路径可以继续存在，以便本地开发；它们不得进入 Git 索引，也不得随公开仓库发布。

## 观察命名空间

公共契约要求：

- 来源为 `official-page` 的观察必须使用 `live` 命名空间；
- 非官方来源必须使用 `simulation` 命名空间。

公共观察仍只允许本地 `official-mock` 写入 `simulation`，官方主机不得上传。精确识别的上海模拟选号和正式选号允许本机读取、高亮、筛选与填入；正式页采集号池使用仅本机的 `live-local` 存储语义。其他未识别官方页保持安全关闭。

## 自动化安全边界

插件可以读取已适配页面中的号码，但保持用户当前选择的随机或自编模式，不主动切换标签。用户亲自进入自编后，助手优先读取号段规则快照并在本地展开候选，白键对不上才退回逐键遍历。官方自编固定前缀只有「沪」。用户提交一组后，助手只在读到剩余自编次数下降的页面回执时自动推进本机队列；上一轮号码随即灰色排除且不能重复加入，可用「恢复上一轮备用」撤销最近一次推进。结果标成可编号段快照，不是已确认实时可用。确认信息页才开放合格证识别，并只允许把本机车辆档案写入对应输入框。品牌型号查询窗口由用户亲自打开、选择和关闭；窗口打开后助手分两栏显示品牌和型号，一点即可填入检索框并点查询。用户确定后，选中的品牌型号写回本机记录。建议先开查询窗再填确认页，避免官方拦截后续开窗。页面上的下一步栏位会用绿色描边提示。随机选号的相同数字（2 次及以上）、好多数（3 次及以上）、三位以上顺序号和位置/顺序规则高亮画在页面号码外框上；强匹配额外显示静态泛光：三连或 AABB、四位以上顺序或四位以上数字回环、同一数字 4 次或多个数字同时命中，以及任何位置/顺序规则命中。相同数字与好多数可指定目标数字，留空匹配全部，连续顺子不含 `0`。核对在确认页放大合格证对应位置。填写后可悬停核对照片对应区域。编号、型号里常见的 0/O、1/I 等 OCR 易混处会标红提醒。插件不得点击验证、确认、提交或最终选号按钮。车辆档案只留在浏览器本地。合格证照片仅在用户主动选文件后发往 OCR.space，不经过 PlateGo 服务器，也不进入公共观察。OCR.space 密钥只保存在插件本机配置，不出现在页面助手。
