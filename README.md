# PlateGo · 号牌沙盘（公开源码）

PlateGo 是一个本地优先的号牌筛选、模拟选号与 Chrome 选号助手。当前公开基线以 **Chrome 插件** 为主，并保留网页模拟器作为开发/历史内容。固定模拟数据随构建产物打包，不依赖私有后端。

> 非官方项目。模拟数据不代表 12123 或任何车管部门的实时可用号码。

## 包含内容

- Chrome MV3 插件：完整独立工作台；上海页面助手的完整采集先在脱敏本地样机中开放，官方模拟选号页允许只读号码、页面外框高亮与当前意向填入。
- 网页模拟器：固定模拟号池、筛选收藏、策略配置、完整模拟选号与配置传输。
- 公共契约与固定模拟数据：31 个省级地区可复现号池、PS1 / `.platecfg` 配置、选号状态机。

网页和插件都能单独运行。自动动作止于读取、填入和退格；验证、确认与提交始终由用户完成。

## 最快开始

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

- 网页与上海官方页样机：<http://127.0.0.1:4173>
- 上海官方页样机：<http://127.0.0.1:4173/official-mock>

网页不依赖后端即可完成免费流程。

## 下载发布版

安装包版本为 **v0.1.1**。从 [PlateGo 下载页](https://platego.ukusik.cc/) 下载 `PlateGo-Chrome-v0.1.1.zip`，解压后双击 macOS 的 `Install.command` 或 Windows 的 `Install-Windows.cmd`。安装助手会校验文件、准备固定目录并打开浏览器扩展管理页，不需要安装 Node.js。

首次仍需在 Chrome 中打开“开发者模式”，点击“加载已解压的扩展程序”，选择助手提供的目录。以后更新安装包后，在扩展页点“重新加载”。完整步骤、系统授权与已有配置迁移说明见[安装与更新指南](docs/INSTALL.md)。

已经从其他目录加载旧版的用户，请先在插件工作台导出配置；更换加载目录可能产生新的扩展 ID。助手不会移除已有扩展或清空浏览器资料。

历史发布见 [GitHub Releases](https://github.com/OttoPrua/PlateGo/releases)，版本变化见[更新日志](CHANGELOG.md)。

## 打包与下载站部署

```bash
npm run package:site
```

该命令生成插件安装 ZIP 和独立 Docker Compose 静态下载站包，输出在 `dist/releases/` 和 `dist/deployment/`。下载站包含公开安装包、中文说明和版本信息；付费授权和真实号池服务尚未随此站点部署。部署说明见 [ops/downloads](ops/downloads/README.zh-CN.md)。

## 加载 Chrome 插件

```bash
npm run build:extension
```

打开 Chrome 的“扩展程序”页面，启用开发者模式，选择“加载已解压的扩展程序”，目录为：

```text
apps/extension/dist
```

完整插件工作台可直接从插件弹窗打开。要测试页面助手：先保持 `npm run dev` 运行并打开本地官方页样机；或在已登录后打开上海官方模拟选号页 `https://sh.122.gov.cn/veh1/netxh/main?gnid=1001`。上海正式选号页仅在精确识别的随机或自编选号内嵌页面中开放本机读取、高亮和填入，确认与提交始终由用户完成。

## 验证命令

```bash
npm run check
```

依次执行 TypeScript 检查、领域/安全契约测试、网页与插件生产构建，以及插件构建校验。

## 公开与私有边界

公开索引不包含：

- 后端共享实现（`services/pool-api`）；
- 购买/时限密钥校验的服务端实现与密钥材料；
- 官方网页私有采集、用户车辆资料和合格证（`private/`）；
- 依赖目录、构建产物和运行时状态。

这些内容可以仍留在本机工作区，但被 `.gitignore` 排除。详见 [公开边界](docs/PUBLIC-SCOPE.md) 与 [12123 还原边界](docs/12123-FIDELITY.md)。

## 重要边界

- 自动动作止于读取、填入和退格；插件没有自动点击验证或提交的代码路径。
- 入口登录、车辆资料、身份验证和短信验证始终由用户完成。
- 偏好规则、收藏、候选顺序、最终选择、身份信息、Cookie 和完整 DOM 不上传。用户主动选择的合格证照片只发给 OCR.space，不经过 PlateGo 服务器。
- 当前网页、插件模拟器和本地样机只写入 `simulation`。
- 配置导出不包含时限密钥或会话令牌。
- 广告仅保留接口，默认使用空实现。
